# Instalar y usar Xpand Pro

## 1. Descargar el APK
1. En GitHub abre la pestaña **Actions** → última ejecución verde de **Compilar APK**.
2. Descarga el artefacto **XpandPro-debug-apk** (es un .zip; dentro está el .apk).
3. Pásalo al teléfono e instálalo (permite "instalar apps desconocidas" si lo pide).

## 2. Instalar y arrancar Shizuku
1. Instala **Shizuku** desde Play Store.
2. Actívalo con **Depuración inalámbrica** (Opciones de desarrollador) siguiendo la guía dentro de Shizuku.
   Hay que repetirlo tras reiniciar el teléfono.

## 3. Usar Xpand Pro
1. Abre Xpand Pro y pulsa **DAR PERMISO** → acepta en Shizuku.
2. Elige el formato (4:3 por defecto) y pulsa **ACTIVAR**.
3. Confirma con **MANTENER** (si no, se restaura sola en 15 s).
4. Abre Blood Strike. Para volver a la normalidad: Xpand Pro → **RESTAURAR**.

Si algo se ve mal: Xpand Pro → RESTAURAR, o Ajustes > Pantalla, o reinicia el teléfono.
